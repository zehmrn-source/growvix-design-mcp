Growvix Design MCP

A free, combined MCP server project designed to bring ReactBits and Unsplash resources into Claude.

Integrations

- ReactBits – UI components, animations and interactive effects.
- Unsplash – High-quality photography and image discovery.
- Claude – AI-assisted website development.

Purpose

To help build modern, responsive and visually appealing websites, including the Growvix website.

Hosting

Cloudflare Workers.

Status

Project setup in progress.
